# References

Use this directory for durable references that help future contributors understand the project context.

## Current Reference Points

- Ant project file: `build.xml`
- NetBeans project config: `nbproject/project.properties`
- Project overview: `README.md` if present
- Servlet configuration: `web/WEB-INF/web.xml`
- Tomcat context: `web/META-INF/context.xml`
- SQL Server schema: `sql/DBFinora.sql`
- AI agent rules: `AGENTS.md`
- Governance docs: `docs/`

Do not store secrets, credentials, private tokens, or temporary notes here.
